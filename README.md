# Noctyra APP

O aplicativo oficial do Noctyra para Android.
Feito com Kotlin e Jetpack Compose.

## Funcionalidades
- Interface moderna e responsiva
- Consumo da API do Noctyra/SushiAnimes
- Player de vídeo integrado
- Carrossel automático

## Como buildar
Abra o projeto no Android Studio e clique em Run ou Build APK.
